Privacy Policy

Last updated: 29 October 2026

Auto Scheduler is a personal tool used only by its owner to upload videos to the owner's own YouTube channels.

YouTube API Services

Auto Scheduler uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What it accesses

With the channel owner's permission, given through Google sign-in (OAuth), it uses the YouTube Data API to upload videos (videos.insert) and to read the connected channel's name (channels.list). It requests no other Google or YouTube data.

How the data is used and stored

The channel name is shown to the owner to confirm the right channel is connected. Sign-in tokens, videos and video details are stored only on the owner's computer. Nothing is sent anywhere except to YouTube when a video is uploaded. No cookies or tracking are used.

Sharing

No data is sold, shared with third parties, or used for advertising.

Deleting data and removing access

Access can be revoked at any time through the Google security settings page at security.google.com/settings/security/permissions. Revoking access, or deleting the local token file, removes all stored YouTube data. Any stored YouTube API data is deleted within 7 days of access being revoked.

Auto Scheduler's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
